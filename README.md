# Student Feedback API

A full-stack Student Feedback application built using Flask, SQLite, JWT Authentication, and Machine Learning.

The application allows users to register and login, submit feedback, view feedback, update and delete feedback, and analyze the sentiment of text using a Machine Learning model.

## Features

- User Registration
- User Login
- JWT Authentication
- Protected API endpoints
- Create feedback
- View feedback
- Update feedback
- Delete feedback
- Input validation
- SQLite database
- AI-based Sentiment Analysis
- Frontend connected with REST APIs
